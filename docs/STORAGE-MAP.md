# نقشه ذخیره‌سازی داده‌ها — TradeBot v2

این سند نشان می‌دهد هر قطعهٔ داده در کجا ذخیره می‌شود. ساختار **دقیقاً مطابق نسخهٔ پایه (پروژهٔ مرجع)** است: تمام داده‌های مهم و حساس سمت **سرور** (پایگاه داده KV) نگهداری می‌شوند و از مرورگر فقط برای تنظیمات ظاهری/محلی استفاده می‌شود — هیچ دادهٔ معاملاتی، کلید یا لاگی در LocalStorage ذخیره نمی‌شود.

## ۱. ذخیره‌سازی سرور (پایگاه داده — KV)

آداپتر: در تولید Cloudflare KV (اتصال `TRADING_DATA`)، در محیط توسعه فایل `db/trading_data.json` (با همان语义/semantics و شمارندهٔ بودجه). کلیدها با نسخهٔ پایه یکسان‌اند (پیشوند `automationState:`):

| کلید | محتوا | نکته |
|---|---|---|
| `automationState:automation_settings` | تنظیمات استراتژی و ریسک (همان فرم صفحهٔ تنظیمات) | مهم — سرور |
| `automationState:settings_apiKeys` | **کلید API و Secret صرافی توبیت** + توکن/چت بله + baseUrl | مهم‌ترین داده؛ فقط سمت سرور خوانده می‌شود و به مرورگر فقط به‌صورت ماسک‌شده (`••••`) برمی‌گردد |
| `automationState:auth_credentials` | نام کاربری + هش شور‌دار رمز + `issuedAt` | **کاملاً جدا از کلیدهای صرافی** — ورود به پنل هرگز مقدار API Key/Secret را تغییر نمی‌دهد (آزمون رگرسیون: `tests/auth-isolation.test.ts`) |
| `automationState:automation_symbols` | فهرست نمادها + وضعیت/خطا/آخرین چرخهٔ هر نماد | در نبود کلید، پیش‌فرض DOT/BTC/ETH (`src/core/symbols.ts`) |
| `automationState:lastCycleResult` | نتیجهٔ کامل آخرین چرخه (شناسهٔ `SYMBOL_YYYYMMDD_HHMMSS`، مراحل، بودجهٔ ذخیره‌سازی) | |
| `logs` | **لاگ یکپارچهٔ چرخه‌ها** — هر مرحلهٔ هر چرخه یک رکورد با جزئیات فنی (حداکثر ۵۰۰ رکورد) | همان جدول «چرخه و رویدادها» |
| `automationState:cycleLock` | قفل اجرای موازی | |
| `automationState:lastPositionCloseTime` | نشانگر نوتیفیکیشن پوزیشن‌های بسته‌شده | |
| `automationState:pendingBaleMessages` | صف پیام‌های بله در صورت خطای شبکه | حداکثر ۵۰ |

## ۲. LocalStorage مرورگر (فقط تنظیمات محلی/ظاهری)

| کلید | محتوا | چرا محلی است؟ |
|---|---|---|
| `tb-theme` | تم روشن/تاریک | ترجیح ظاهری هر مرورگر — مثل نسخهٔ پایه |
| `tb-sidebar-collapsed` | باز/بسته بودن نوار کناری | فقط حالت رابط کاربری |
| `tradebot.chart.customSymbols` | نمادهای دلخواه اضافه‌شده در تولبار چارت | مثل نسخهٔ پایه — فهرست شخصی ابزار نمایشی، نه دادهٔ معاملاتی |

> رسم‌های چارت (drawing) مانند نسخهٔ پایه فقط در حافظهٔ جلسهٔ جاری نگهداری می‌شوند (با رفرش پاک می‌شوند).

## ۳. داده‌ای که هرگز ذخیره نمی‌شود

- کندل‌ها/قیمت‌های لحظه‌ای: هر بار مستقیم از API توبیت خوانده می‌شوند.
- پوزیشن‌های باز و موجودی: همیشه زنده از صرافی (`/api/positions/open`، `/api/account/balance`).
- رمز عبور و کلید Secret: **هیچ‌وقت** به‌صورت متن آشکار ذخیره یا به مرورگر فرستاده نمی‌شوند.
