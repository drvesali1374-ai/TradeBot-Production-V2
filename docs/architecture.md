# معماری نسخه جدید TradeBot (v2)

## نمای کلی
پلتفرم معاملات خودکار رمزارز (Futures توبیت) با استراتژی Fake Breakout.
- **فریمورک:** Next.js 16 (App Router) + TypeScript strict
- **اجرا:** توسعه محلی (Bun/Node) → استقرار Cloudflare Pages + Cron Worker
- **ذخیره‌سازی:** رابط KV مشترک — LocalAdapter (فایل JSON) در توسعه / KV Adapter در تولید

## لایه‌ها و قواعد وابستگی
```
src/core/      ← محاسبات خالص (بدون وابستگی به API/KV/UI)
src/server/    ← اجرای سروری: صرافی، ذخیره‌سازی، احراز هویت، موتور چرخه
src/app/api/   ← اعتبارسنجی HTTP + فراخوانی سرویس (بدون منطق تجاری)
src/modules/   ← رابط کاربری هر بخش (React)
```
- **هیچ محاسبه تجاری در دو جا تکرار نمی‌شود** — RSI/ATR/SMA/سیگنال/TP-SL/ریسک فقط در `src/core` تعریف شده‌اند و هم موتور سرور و هم API تحلیل از همان استفاده می‌کنند.
- **تمام تماس‌های صرافی فقط از `src/server/exchanges/toobit/client.ts`** — کاتالوگ endpoint در `endpoints.ts`، امضا در `signing.ts`.
- **کلیدهای API فقط سمت سرور** — هرگز به باندل مرورگر نمی‌روند؛ GET تنظیمات کلیدها را ماسک می‌کند.

## موتور چرخه (اجرای واحد)
`src/server/automation/cycle-engine.ts` — تنها مسیر اجرای معامله. دو ورودی:
1. `POST /api/automation/run-cycle` (دستی — دکمه «یک چرخه»، با Session)
2. `POST /api/internal/cron` (زمان‌بندی‌شده — با هدر `X-Cron-Secret`)

هر دو **همان تابع `runCycle`** را صدا می‌زنند. هیچ زمان‌بند مرورگری وجود ندارد (§10.1).

### مراحل چرخه
1. cycleId + بارگذاری یک‌باره تنظیمات/نمادها  8. قیمت + موجودی + پوزیشن‌ها
2. قفل اجرا (TTL 90s)                        9. بستن پوزیشن مخالف (با تأیید)
3. انتخاب نماد آماده (tradeWaitTime)         10. مارجین + ۶ کنترل ریسک
4. دریافت کندل‌ها (کندل بسته صریح)           11. ثبت سفارش (ToobitClient)
5. اندیکاتورها + تولید سیگنال (core)        12. تأیید سفارش + TP/SL
6. انتخاب سیگنال + انقضا                     13. اعلان بله
7. —                                          14. persist واحد + آزادسازی قفل

## قفل هم‌زمانی
KV اتمیک نیست؛ راهکار: قفل با TTL (`cycle-lock.ts`) + نوشتن فوری `lastCycleTime` (رفتار مرجع).
ریسک باقیمانده: دو نویسنده هم‌زمان در پنجره میلی‌ثانیه‌ای — پذیرفته‌شده با کادنس ۵ دقیقه‌ای کرون؛ برای حذف کامل، Durable Object پیشنهاد می‌شود.

## نبود اعتبارنامه صرافی
بدون کلید API: داده بازار عمومی واقعی کار می‌کند؛ هر عملیات حساب/سفارش با خطای
صریح `NO_CREDENTIALS` («اعتبارنامه صرافی تنظیم نشده است») متوقف می‌شود — حالت
شبیه‌سازی از محصول حذف شده است (مأموریت فاز ۶).
(با قیمت زنده و بستن خودکار TP/SL). هدف: آزمایش کامل چرخه بدون ریسک مالی (§9 حالت اول).

## بودجه نوشتن KV (هدف ≤ 864/day)
هر چرخه ≈ 3 نوشتن: `automation_symbols` (آغاز) + `lastCycleResult` + append آرایه `logs` (سقف ۵۰۰).
WriteBatcher فقط مقادیر «واقعاً تغییرکرده» را می‌نویسد؛ شمارنده‌ها در `/api/diagnostics/storage`.

## رگرسیون‌های اصلاح‌شده نسبت به مرجع (مستند)
1. **RSI off-by-one** — آرایه هم‌تراز طول N (مستند در `core/indicators/rsi.ts`)
2. **کندل بسته** — فیلتر صریح `closeTime ≤ now` به‌جای حذف اندیس آخری
3. **HTF** — فقط `signalCandleClose` (بدون lookahead داشبورد قدیمی)
4. کلید هاردکد حذف شد؛ همه مسیرهای حساس احراز هویت دارند
5. شکست TP/SL به‌عنوان هشدار گزارش می‌شود (نه بی‌صدا)
6. شناسه پایدار سیگنال: `SYMBOL_SIDE_candleOpenTime_v1` (idempotency)
7. تفکیک زمان‌ها: candleOpenTime / signalConfirmedAt / orderSubmittedAt
8. آمار از historyPositions واقعی (آرایه trades مرده حذف شد)
