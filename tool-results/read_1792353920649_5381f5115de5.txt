   139→   139→### A.6 Step 1 — `selectNextSymbol()` (symbol selection)
   140→   140→```ts
   141→   141→const now = Date.now()
   142→   142→const waitTimeMs = automationSettings.tradeWaitTime * 60 * 1000  // tradeWaitTime in MINUTES
   143→   143→const readySymbols = symbols.filter(s => !s.lastCycleTime || (now - s.lastCycleTime >= waitTimeMs))
   144→   144→let symbol = options.symbolOverride
   145→   145→  ? symbols.find(s => s.name === options.symbolOverride) || null   // override ignores wait time
   146→   146→  : (readySymbols.length > 0 ? readySymbols[0] : null)            // FIRST ready in list order
   147→   147→```
   148→   148→- Empty symbols list → warning log `هیچ نمادی در لیست اتوماسیون وجود ندارد`, return `{success:false, action:'no_ready_symbol', errorCount:0}`.
   149→   149→- No ready symbol → warning `هیچ نمادی برای معامله آماده نیست`, same no_ready_symbol return.
   150→   150→- Log: `شروع چرخه برای نماد {name}`.
   151→   151→- **allowedErrors** is NOT used in selection — it's only used in the catch block: when a cycle throws, errorCount++ via KV read-modify-write; if `errorCount >= allowedErrors` → reset errorCount=0, status='waiting', lastCycleTime=Date.now() (symbol skipped, notification `#عبور_نماد`), else status='error' (notification `#خطا`).
   152→   152→- After selection: `updateSymbolState`/`updateSymbolStateInMemory` are BOTH in-memory-only helpers now (Transaction Buffer); but immediately after selection there IS one real KV write: `symbols[idx] = {..., lastCycleTime: Date.now()}; await AutomationState.set('automation_symbols', symbols)` (with try/catch fallback to in-memory). Rationale: next cron (5 min later) must re-read updated lastCycleTime so it doesn't re-select the same symbol.

   161→   161→### A.8 Step 4 — analyzeMarketData (signal generation, verbatim port)
   162→   162→- Candle mapping: `timestamp = new Date(c[0])`, `open/high/low/close = parseFloat(c[1..4])`, `amount = parseFloat(c[5])`.
   163→   163→- **Daily levels with Tehran offset**: `offset = 3.5*3600*1000`; `day = Math.floor((ts + offset)/86400000)`; `dailyData[day] = {maxHigh, minLow, lastClose, lastTs}`. Per-candle arrays `prevDailyHighs[i]`, `prevDailyLows[i]`, `prevDayCloses[i]` (null for first day).
   164→   164→- Indicators:
   165→   165→  - `ATR(period=atrPeriod||14)`: TR = max(high-low, |high-prevClose|, |low-prevClose|); `atr[0]=TR[0]`; `atr[i] = ((period-1)*atr[i-1] + TR[i]) / period`.
   166→   166→  - `avgVols = SMA(amount, avgVolPeriod||50)` — plain rolling mean, null before period-1.
   167→   167→  - `RSI(period=rsiPeriod||14)`: first `period` values null; seed avgGain/avgLoss = sum/period; Wilder smoothing `avgGain = (avgGain*(p-1)+gain)/p`; `rs = avgLoss===0 ? 100 : avgGain/avgLoss`; `rsi = 100 - 100/(1+rs)`.
   168→   168→- Crossover trackers (legacy path): `lastCrossUnderPL` / `lastCrossOverPH` = bars since close crossed under prev-day Low / over prev-day High (Infinity if never).
   169→   169→- **Meaningful break trackers** (filter enabled by default): `bdLong = atr[i]*breakAtrMultiplierLong`, `bdShort = atr[i]*breakAtrMultiplierShort`; Wick method: `mbl = prevDailyLows[i] !== null && data[i].low <= prevDailyLows[i] - bdLong`; `mbs = high >= prevDailyHighs[i] + bdShort`; Close method uses `close` instead of low/high. Track `lastMeaningfulBreakLong/Short[i] = i - lastIdx` (Infinity if none).
   170→   170→- **HTF confirmation** (`htfSource = marketSettings.htfConfirmationSource || 'signalCandleClose'`):
   171→   171→  - `'previousDayClose'`: htfConfirmLong = `prevDayCloses[i] !== null && prevDayCloses[i] > prevDailyLows[i]`; htfConfirmShort = `prevDayCloses[i] !== null && prevDayCloses[i] < prevDailyHighs[i]`.
   172→   172→  - default (`'signalCandleClose'`): htfConfirmLong = `prevDailyLows[i] !== null && data[i].close > prevDailyLows[i]`; htfConfirmShort = `prevDailyHighs[i] !== null && data[i].close < prevDailyHighs[i]`.
   173→   173→- Loop `for (i = 1; i < N-1; i++)` (last candle excluded — needs a completed candle):
   174→   174→  - **Branch A (default, `enableBreakLifecycleManagement !== false`) — Break Lifecycle state machine**:
   175→   175→    - `BreakState { active, type:'Long'|'Short'|null, breakCandleIndex, waitingRecovery, recovered, recoveryCandleIndex }`, `resetBreakState()` all-zero.
   176→   176→    - 1) Expiry: `lifetime = breakSequenceLifetime > 0 ? breakSequenceLifetime : (marketSettings.lookback || 50)`; if `i - breakCandleIndex > lifetime` → reset.
   177→   177→    - 2) New meaningful break (if `!active || recovered`): Long break (low/close <= prevLow − bdLong) → state Long/waitingRecovery; else Short break (high/close >= prevHigh + bdShort) → state Short.
   178→   178→    - 3) Opposite break while waiting → replace state with the new direction.
   179→   179→    - 4) Recovery: Long → `close > prevDailyLow`; Short → `close < prevDailyHigh` → set `recovered=true, recoveryCandleIndex=i, waitingRecovery=false`.
   180→   180→    - 5) Signal ONLY on the recovery candle (`recovered && recoveryCandleIndex === i`):
   181→   181→      - `condLong = avgVols[i] !== null && amount > avgVols[i] * (volMultLong ?? marketSettings.volMult ?? 0.2) && rsi[i] !== null && rsi[i] < (rsiLongThreshold ?? marketSettings.rsiThreshold ?? 30) && htfConfirmLong`
   182→   182→      - `condShort = avgVols[i] !== null && amount > avgVols[i] * (volMultShort ?? marketSettings.volMult ?? 0.2) && rsi[i] !== null && rsi[i] > (rsiShortThreshold ?? marketSettings.rsiThreshold ?? 70) && htfConfirmShort`
   183→   183→      - TP/SL (Long): `longFixedTp` (non-null, non-NaN) → `tp = close + close*(longFixedTp/100)` else `tp = close + atr[i]*(tpLongMult||20)`; `longFixedSl` → `sl = close - close*(longFixedSl/100)` else `sl = close - atr[i]*(slLongMult||6)`.
   184→   184→      - TP/SL (Short): `shortFixedTp` → `tp = close - close*(shortFixedTp/100)` else `tp = close - atr[i]*(tpShortMult||24)`; `shortFixedSl` → `sl = close + close*(shortFixedSl/100)` else `sl = close + atr[i]*(slShortMult||4)`.
   185→   185→      - `clientOrderId = generateOrderId(timestamp, symbolName)` = `{SYMBOL}_{YYYYMMDD}_{HHMMSS}`.
   186→   186→      - Push `Signal{type, timestamp, price: close, tp, sl, orderId, symbol, candleIndex: i}`; set `data[i].signal/tp/sl/clientOrderId`.
   187→   187→      - Reset break state (break consumed whether or not signal fired).
   188→   188→  - **Branch B (legacy, `enableBreakLifecycleManagement === false`)**:
   189→   189→    - `isCrossOverPL = close > prevLow && prevClose <= prevLow(prev i-1)`; `isCrossUnderPH = close < prevHigh && prevClose >= prevHigh(prev)`.
   190→   190→    - `recentBreakLong = enableMeaningfulBreakFilter ? lastMeaningfulBreakLong[i] : lastCrossUnderPL[i]`; `recentBreakShort = ... lastMeaningfulBreakShort/lastCrossOverPH`.
   191→   191→    - `condLong = isCrossOverPL && recentBreakLong <= (lookback||50) && <vol filter> && <RSI < 30-ish> && htfConfirmLong`; `condShort` mirrored.
   192→   192→    - Same TP/SL/orderId/signal emission as branch A.

   277→   277→### A.18 The 6 risk controls (order, formulas, messages)
   278→   278→PROJECT_INDEX ordering: ۱ دارایی امن, ۲ فاصله قیمت, ۳ سقف مارجین نماد, ۴ مارجین مثبت, ۵ حداقل کندل هم‌جهت, ۶ انقضای سیگنال. Engine execution order: min-candles (after step 8) → safe asset → price distance + max margin (conditional) → positive margin; expiration is in step 6.
   279→   279→
   280→   280→**Control 6 — Signal expiration (مورد ۴)**: in updateSelectedSignal (A.10). Status `'منقضی شده'` when `(now - signalTime) > signalExpirationHours*3600e3`.
   281→   281→
   282→   282→**Control — Min Same-Direction Candles (مورد ۶)**: see A.13. Hashtag `#کندل_هم‌جهت`.
   283→   283→
   284→   284→**Control 1 — Safe Asset (دارایی امن) — ALWAYS runs**:
   285→   285→- `safeAmount = totalAssets * (safeAssetPercent / 100)`; `projectedFree = freeBalance - newMargin`; reject if `projectedFree < safeAmount`.
   286→   286→- Log: `{name}: دارایی امن کافی نیست (آزاد {free} - مارجین {margin} = {projectedFree} < دارایی امن {safeAmount}) — رد شد`
   287→   287→- Notification math (control name `دارایی امن (Safe Asset)`, hashtag `#دارایی_امن`):
   288→   288→```
   289→   289→کل دارایی = {totalAssets.toFixed(4)} USDT
   290→   290→موجودی آزاد = {freeBalance.toFixed(4)} USDT
   291→   291→مارجین ورودی جدید = {newMargin.toFixed(4)} USDT
   292→   292→درصد دارایی امن = {safeAssetPercent}%
   293→   293→دارایی امن = {totalAssets.toFixed(4)} × {safeAssetPercent}% = {safeAmount.toFixed(4)} USDT
   294→   294→موجودی آزاد پیش‌بینی‌شده = {freeBalance.toFixed(4)} - {newMargin.toFixed(4)} = {projectedFree.toFixed(4)} USDT
   295→   295→{projectedFree.toFixed(4)} < {safeAmount.toFixed(4)} ✗
   296→   296→```
   297→   297→
   298→   298→**Control 2 — Price Distance (فاصله قیمت) — ONLY if symbol found in freshOpenPositions AND symbolLastEntryPrice !== null**:
   299→   299→- Long: `distancePercent = ((symbolLastEntryPrice - price) / symbolLastEntryPrice) * 100`
   300→   300→- Short: `distancePercent = ((price - symbolLastEntryPrice) / symbolLastEntryPrice) * 100`
   301→   301→- Reject if `distancePercent < effMinPriceDistancePercent`.
   302→   302→- Log: `فاصله قیمت کافی نیست (آخرین ورود: {last}, فعلی: {price}, فاصله: {d}% < {min}%) — رد شد` / pass: `فاصله قیمت OK ({d}% ≥ {min}%)`; if no last entry: `آخرین ورود هم‌جهت در تاریخچه یافت نشد — کنترل قیمت انجام نشد`.
   303→   303→- Notification math (name `فاصله قیمت (Price Distance)`, hashtag `#فاصله_قیمت`):
   304→   304→```
   305→   305→آخرین قیمت ورود هم‌جهت = {symbolLastEntryPrice}
   306→   306→قیمت فعلی = {price}
   307→   307→جهت سیگنال = {لانگ|شورت}
   308→   308→فاصله = (آخرین ورود - فعلی) / آخرین ورود × 100        ← Long variant
   309→   309→فاصله = ({last} - {price}) / {last} × 100
   310→   310→فاصله = {distancePercent.toFixed(4)}%
   311→   311→حداقل فاصله قیمت = {effMinPriceDistancePercent}%
   312→   312→{d.toFixed(4)}% < {min}% ✗
   313→   313→```
   314→   314→(Short formula line: `فاصله = (فعلی - آخرین ورود) / آخرین ورود × 100`)
   315→   315→
   316→   316→**Control 3 — Max Margin Per Symbol (سقف مارجین) — ONLY if symbol in freshOpenPositions**:
   317→   317→- `existingSymbolMargin = parseFloat(symbolPosition.margin || 0)`; `maxMarginPerSymbol = totalAssets * (maxMarginPerSymbolPercent / 100)`; `totalSymbolMargin = existingSymbolMargin + newMargin`; reject if `totalSymbolMargin > maxMarginPerSymbol`.
   318→   318→- Log: `سقف مارجین نماد ({total} > {max} USDT) — رد شد` / pass `مارجین نماد OK ({total} ≤ {max} USDT)`.
   319→   319→- Notification math (name `سقف مارجین نماد (Max Margin Per Symbol)`, hashtag `#سقف_مارجین`):
   320→   320→```
   321→   321→کل دارایی = {totalAssets.toFixed(4)} USDT
   322→   322→درصد سقف مارجین نماد = {maxMarginPerSymbolPercent}%
   323→   323→سقف مارجین نماد = {totalAssets.toFixed(4)} × {maxMarginPerSymbolPercent}% = {maxMarginPerSymbol.toFixed(4)} USDT
   324→   324→مارجین موجود نماد = {existingSymbolMargin.toFixed(4)} USDT (از ستون «مارجین» جدول پوزیشن‌های باز)
   325→   325→مارجین ورودی جدید = {newMargin.toFixed(4)} USDT
   326→   326→مجموع مارجین نماد = {existing.toFixed(4)} + {newMargin.toFixed(4)} = {totalSymbolMargin.toFixed(4)} USDT
   327→   327→{total.toFixed(4)} > {max.toFixed(4)} ✗
   328→   328→```
   329→   329→- If symbol NOT in open positions: log `نماد در پوزیشن‌های باز یافت نشد — کنترل‌های فاصله قیمت و سقف مارجین skip شدند`.
   330→   330→
   331→   331→**Control 4 — Positive Margin (مارجین مثبت) — ALWAYS runs**:
   332→   332→- `finalMargin = Math.max(newMargin, 0)`; reject if `finalMargin <= 0`. Log `مارجین نهایی صفر یا منفی — رد شد`.
   333→   333→- Notification math (name `مارجین مثبت (Positive Margin)`, hashtag `#مارجین_مثبت`):
   334→   334→```
   335→   335→کل دارایی = {totalAssets.toFixed(4)} USDT
   336→   336→درصد مارجین ورودی = {effEntryMarginPercent}%
   337→   337→مارجین محاسبه‌شده = {totalAssets.toFixed(4)} × {effEntryMarginPercent}% = {newMargin.toFixed(4)} USDT
   338→   338→مارجین نهایی = max({newMargin.toFixed(4)}, 0) = {finalMargin.toFixed(4)} USDT
   339→   339→{finalMargin.toFixed(4)} ≤ 0 ✗
   340→   340→```
   341→   341→All risk blocks return `{ success:false, action:'risk_blocked', errorCount:0, symbols }` and set symbol status 'waiting' in-memory.

   590→   590→## A. Indicator Math (signal-utils.js, class SignalUtils, static methods)
   591→   591→
   592→   592→### A.1 RSI — calculateRSI(data, period=14)
   593→   593→- **Smoothing: Wilder (RMA)** after a simple-average seed.
   594→   594→- Pseudocode (i loops 1..N-1 over candles):
   595→   595→  - change = close[i] − close[i−1]; gain = max(change,0); loss = max(−change,0)
   596→   596→  - if i ≤ period: avgGain += gain; avgLoss += loss; at i === period → avgGain /= period; avgLoss /= period; **push null**
   597→   597→  - if i > period: avgGain = (avgGain·(period−1) + gain)/period; avgLoss = same; rs = (avgLoss === 0 ? 100 : avgGain/avgLoss); push 100 − 100/(1+rs)
   598→   598→- **CRITICAL INDEX-ALIGNMENT BUG (verified with node):** `rsiValues.push()` runs once per loop iteration i=1..N-1 → returned array has **length N−1**, and the value pushed at iteration i lands at **array index i−1**. Therefore `rsi[k]` is the RSI of **candle k+1**.
   599→   599→  - All callers (automation-manager analyzeMarketData AND market-signal-analyzer analyzeData) do `rsi[i]` while iterating candle i → they evaluate the RSI of the **NEXT candle (i+1)** = **1-candle lookahead**. On the last analyzed candle (i=N−2) they read the RSI of candle N−1 = the **still-forming candle** → live repainting.
   600→   600→  - Also first non-null value appears at array index `period` (= candle period+1), one candle later than textbook Wilder (first RSI at candle `period`); nulls occupy rsi[0..period−1].
   601→   601→  - `data[i].rsi = rsi[i]` also stores the shifted value → market-data table shows candle i+1's RSI on row i.
   602→   602→- Quirk: when avgLoss = 0 → rs forced to 100 → RSI = 100 − 100/101 = **99.0099…** (never exactly 100).
   603→   603→- if data.length < period → array of nulls.
   604→   604→
   605→   605→### A.2 ATR — calculateATR(data, period=14)
   606→   606→- TR[0] = high[0] − low[0]; TR[i] = max(high[i]−low[i], |high[i]−prevClose|, |low[i]−prevClose|).
   607→   607→- atr[0] = TR[0]; atr[i] = ((period−1)·atr[i−1] + TR[i]) / period → **Wilder RMA**, but **seeded with the single first TR** (not SMA of first `period` TRs — non-standard warm-up; converges asymptotically).
   608→   608→- Array is **index-aligned** with candles (length N). No off-by-one. Default period 14.
   609→   609→
   610→   610→### A.3 SMA — calculateSMA(data, period)
   611→   611→- sma[i] = mean(x[i−period+1 .. i]) for i ≥ period−1, else **null**. Accepts objects (uses `.close`) or raw numbers.
   612→   612→- avgVols = SMA over candle **`amount`** (Toobit kline field index 5), period = avgVolPeriod (default 50). Index-aligned; null for first 49 candles. In automation: `SignalUtils.calculateSMA(data.map(d => d.amount), avgVolPeriod)`.

   632→   632→### B.2 Daily levels (previous-day H/L/C)
   633→   633→- **offset = 3.5·3600·1000 = UTC+3:30 (Iran) → day boundary = midnight Tehran.**

   635→   635→- Per dayKey bucket: maxHigh = running max(high), minLow = running min(low), lastClose = close of the candle with the **largest localTs** in that day (for the current, incomplete day this is the still-forming candle's close), lastTs.
   636→   636→- days = sorted dayKeys. For each candle i: prevDay = days[days.indexOf(dayKey(i)) − 1] → **previous day PRESENT IN DATA** (gaps skipped); arrays prevDailyHighs[i], prevDailyLows[i], prevDayCloses[i] (automation) = that day's maxHigh/minLow/lastClose; null if no earlier day.
   637→   637→- Dashboard extra: dates[i] = new Date(dayKey·86400000 − offset) (day midnight) and **dailyCloses[i] = current day's lastClose** (used for its HTF check — lookahead for historical candles).
   638→   638→
   639→   639→### B.3 Meaningful-break conditions (used by state machine AND by filter)
   640→   640→- breakDistanceLong = (atr[i]‖0) · breakAtrMultiplierLong (default 0.20; fallback chain: breakAtrMultiplierLong → legacy breakAtrMultiplier → 0.20). Same for Short.
   641→   641→- **Wick method (default):** isMeaningfulBreakLong = prevDailyLows[i] ≠ null && **low[i] ≤ prevDailyLows[i] − breakDistanceLong**; isMeaningfulBreakShort = prevDailyHighs[i] ≠ null && **high[i] ≥ prevDailyHighs[i] + breakDistanceShort**.
   642→   642→- **Close method:** close[i] ≤ prevDailyLows[i] − dist / close[i] ≥ prevDailyHighs[i] + dist.
   643→   643→- Directional multipliers are Phase-17 additions (breakAtrMultiplierLong/Short, defaults 0.20).
   644→   644→
   645→   645→### B.4 Break Lifecycle state machine (enableBreakLifecycleManagement, default **true**)
   646→   646→- State: `{ active, type: 'Long'|'Short'|null, breakCandleIndex, waitingRecovery, recovered, recoveryCandleIndex }`; reset = all null/false.
   647→   647→- Main loop: **for i = 1; i < N − 1** (candle 0 and the LAST candle excluded — last candle = still forming).
   648→   648→- Per candle, in order:
   649→   649→  1. **Expiry:** if active && !recovered && (i − breakCandleIndex > lifetime) → reset. lifetime = breakSequenceLifetime > 0 ? breakSequenceLifetime : (lookback ‖ 50) → **default 50 candles** (breakSequenceLifetime default 0 = use lookback).
   650→   650→  2. **New break:** if (!active || recovered) → Long meaningful break sets {active, type Long, breakCandleIndex i, waitingRecovery true}; else Short break similarly.
   651→   651→  3. **Replacement:** if active && !recovered → an **opposite-direction** meaningful break REPLACES the state (new breakCandleIndex = i). A same-direction new break while waiting is ignored (original break candle kept, so expiry counts from the original break).
   652→   652→  4. **Recovery:** if active && waitingRecovery → Long: **close[i] > prevDailyLows[i]** (closes back above prev-day low); Short: **close[i] < prevDailyHighs[i]**. NOTE: level is prevDailyLows[i] **of the recovery candle's own day context** (not frozen at break time; across midnight the reference level shifts to the previous day = the break day). Sets recovered = true, recoveryCandleIndex = i, waitingRecovery = false.
   653→   653→  5. **Signal on the recovery candle:** if recovered && recoveryCandleIndex === i → evaluate entry conditions (B.5); then **breakState = resetBreakState() unconditionally** (break consumed whether or not a signal fired).
   654→   654→- **Same-candle fake-out possible:** break (deep wick beyond level) and recovery (close back inside) can be the SAME candle i → signal on that candle.
   655→   655→
   656→   656→### B.5 Entry conditions (evaluated on the recovery candle in SM mode)
   657→   657→- Long: avgVols[i] ≠ null && **amount[i] > avgVols[i] · volMultLong** (default 0.2; fallback autoSettings.volMultLong ?? settings.volMult ?? 0.2) && rsi[i] ≠ null && **rsi[i] < rsiLongThreshold** (default 30; fallback ?? settings.rsiThreshold ?? 30) && htfConfirmLong.
   658→   658→- Short: amount[i] > avgVols[i] · volMultShort (0.2) && **rsi[i] > rsiShortThreshold** (default 70) && htfConfirmShort.
   659→   659→- Volume note: threshold is only **> 0.2× average volume** → a minimum-volume sanity bar, not a surge filter.
   660→   660→- RSI note: strict `<` / `>`; but remember rsi[i] is actually candle i+1's RSI (A.1).
   661→   661→
   662→   662→### B.6 Legacy branch (enableBreakLifecycleManagement = false) — "original" logic
   663→   663→- isCrossOverPL = close[i] > prevDailyLows[i] && close[i−1] ≤ prevDailyLows[i−1]  (close crosses back ABOVE prev-day low)
   664→   664→- isCrossUnderPH = close[i] < prevDailyHighs[i] && close[i−1] ≥ prevDailyHighs[i−1]
   665→   665→- recentBreakLong = enableMeaningfulBreakFilter ? lastMeaningfulBreakLong[i] : lastCrossUnderPL[i]; must be ≤ lookback (50). Trackers store "candles since last event" (∞ if never): lastCrossUnderPL from plain close-cross-below-prev-low; lastMeaningfulBreakLong from B.3 conditions.
   666→   666→- condLong = isCrossOverPL && recentBreakLong ≤ lookback && volume && RSI && htf; condShort mirrored. Then same TP/SL + signal push as SM mode (but WITHOUT candleIndex? — no, legacy branch also pushes candleIndex).
   667→   667→- Note: the i−1 comparison uses the previous candle's **own** prev-day level → at Tehran-midnight boundaries the level value changes, which can fabricate a "cross".
   668→   668→
   669→   669→### B.7 HTF confirmation (htfConfirmationSource)
   670→   670→- **'signalCandleClose' (default):** htfConfirmLong = close[i] > prevDailyLows[i]; htfConfirmShort = close[i] < prevDailyHighs[i] (signal candle's own close back inside prior-day range).
   671→   671→- **'previousDayClose':** htfConfirmLong = prevDayCloses[i] > prevDailyLows[i]; htfConfirmShort = prevDayCloses[i] < prevDailyHighs[i] (prev-day close vs prev-day levels).
   672→   672→- Dashboard variant (DIFFERENT): htfConfirmLong = dailyCloses[i] > prevDailyLows[i] where dailyCloses[i] = **current day's last close** → uses future/forming close on historical candles (lookahead).
   673→   673→
   674→   674→### B.8 TP/SL formulas (exact; entry price = close[i] of signal candle)
   675→   675→- Long:
   676→   676→  - tp = (longFixedTp ≠ null && !NaN) ? close + close·(longFixedTp/100) : close + **atr[i]·tpLongMult** (default 20)
   677→   677→  - sl = (longFixedSl ≠ null) ? close − close·(longFixedSl/100) : close − **atr[i]·slLongMult** (default 6)
   678→   678→- Short:
   679→   679→  - tp = (shortFixedTp ≠ null) ? close − close·(shortFixedTp/100) : close − **atr[i]·tpShortMult** (default 24)
   680→   680→  - sl = (shortFixedSl ≠ null) ? close + close·(shortFixedSl/100) : close + **atr[i]·slShortMult** (default 4)
   681→   681→- **DEFAULT QUIRK:** shortFixedSl default = **6 (not null)** → shorts default to %-based SL (close·1.06) while their TP is ATR-based; longs are fully ATR-based by default. Fixed values are PERCENT of entry (not absolute prices).
   682→   682→
   683→   683→### B.9 Signal object (this.signals.push)
   684→   684→```
   685→   685→{
   686→   686→  type: 'Long' | 'Short',
   687→   687→  timestamp: Date,        // candle OPEN time of the signal candle
   688→   688→  price: close[i],        // entry price = signal candle close
   689→   689→  tp: Number, sl: Number,
   690→   690→  orderId: clientOrderId, // `${symbol}_YYYYMMDD_HHMMSS` (local tz of candle timestamp)
   691→   691→  symbol: symbol,
   692→   692→  candleIndex: i          // automation only; used by minSameDirectionCandles risk control
   693→   693→}
   694→   694→```
   695→   695→- Candle row also gets: data[i].signal, .tp, .sl, .clientOrderId, .rsi, .atr (for table/chart/CSV).
   696→   696→- No `status`/`reason` fields on the object — status is computed at render time. Dashboard signal objects lack candleIndex.
   697→   697→- Persisted per symbol under DB keys: marketData_{sym}, processedData_{sym}, signals_{sym}, selectedSignal_{sym}, history_{sym}; signals serialized with timestamp → restored with new Date(...).

   699→   699→### B.10 Signal ID generation
   700→   700→- `SignalUtils.generateOrderId(candleTimestamp, symbol)` → `SYMBOL_YYYYMMDD_HHMMSS` in **runtime-local timezone**. One-sight-uniqueness: same symbol + same second → collision (max 1 signal per candle, so collisions only across reloads/pages).
   701→   701→- At position open, openPosition() generates a **new** clientOrderId from `Date.now()` — signal orderId is display/reference only.
   702→   702→- close-position order id: `${symbol}_close_${Date.now()}`.

   704→   704→### B.11 calculateSignalStatus(signal) — automation version
   705→   705→- openPositions = currentSymbolHistory.filter(pos.side includes 'OPEN' && includes ('BUY' for Long / 'SELL' for Short)) — sides are Toobit history strings like BUY_OPEN / SELL_OPEN.
   706→   706→- nextSignal = next element of this.signals; window = [signalTime, nextSignalTime) (nextTime = ∞ for latest).
   707→   707→- matching = open positions with posTime in window:
   708→   708→  - none → latest signal? → **'در انتظار'** (waiting, yellow) unless expired → **'منقضی شده'** (expired, orange); non-latest → **'باز نشده'** (never opened, gray).
   709→   709→  - matched → text = **earliest matching position's open time** formatted fa-IR (green) — acts as "opened at …". There is NO literal 'باز شده' string in the code.
   710→   710→- isSignalExpired(signal): (Date.now() − signalTime) > (settings.signalExpirationHours ‖ 6)·3600·1000. **Expiration only applies to the LATEST signal** and only when no matching position opened.
   711→   711→- updateSelectedSignal(): selectedSignal = latest signal ONLY if status.text === 'در انتظار'; expired/latest-opened → not selected (ready-signal card empty). Rendered in renderSelectedSignal().
   712→   712→- Dashboard calculateSignalStatus: same matching logic but no expiration and early-returns if there are no OPEN positions at all.
   713→   713→
   714→   714→### B.12 Candle-closed detection
   715→   715→- **NO explicit openTime + interval vs now check exists.** The kline endpoint returns the in-progress candle as the last array element; the signal loop `for (i = 1; i < N − 1; i++)` **excludes the last candle** (treats it as forming) and also candle 0. Everything is recomputed from a full refetch each cycle.
   716→   716→- Cycle engine timing: automation `setInterval(runCycle, 5·60·1000)` (every 5 min); per-symbol throttle `selectNextSymbol()` requires now − lastCycleTime ≥ tradeWaitTime·60·1000 (default 60 min); first ready symbol in list order is picked.
   717→   717→- Caveats: (1) RSI off-by-one leaks the forming candle's RSI into the last analyzed candle (A.1); (2) minSameDirectionCandles confirmation counts the forming last candle (below).
   718→   718→
   719→   719→### B.13 minSameDirectionCandles (risk control #6, at TRADE time not signal time)
   720→   720→- If > 0 (default 0 = off): sigIdx = selectedSignal.candleIndex; candlesAfterSignal = currentSymbolData.length − sigIdx − 1 (**includes the forming last candle**). If < N → reject (wait for more candles). Then candles sigIdx+1 … sigIdx+N must ALL match: Long → green (close > open), Short → red (close < open). Any opposite candle (or doji: close === open fails both) → reject with Bale risk-control notification. Runs AFTER closeOppositePositions, BEFORE refreshing history/opening.

   722→   722→### B.14 runCycle order (context for rebuild)
   723→   723→1. selectNextSymbol (wait-time throttle) → 2. setupForCycle() clears data/UI (currentSymbolHistory kept until here) → 3. fetchMarketData → 4. updateVisualization → analyzeMarketData → 5. fetchPositionHistory (limit 100; mapped {time,symbol,price,qty,commission,side,realizedPnl}) → 6. render + updateSelectedSignal → 7. if no selectedSignal → skip symbol (waiting, errorCount 0) → 8. fetchPrice (latest 1h kline close from /api/toobit-proxy) → 9. closeOppositePositions (opposite side market close; capture closedPositionInfo) → 10. minSameDirectionCandles → 11. refresh history + open positions (X-API-Key headers from marketSignalSettings) → 12. fetchBalance → 13. calculateNewMargin = totalAssets·(entryMarginPercent/100), toFixed(2) → 14. checkSafeAsset: free − newMargin ≥ totalAssets·(safeAssetPercent/100) → 15. (only if symbol in open positions) price-distance: Long (lastEntry−current)/lastEntry·100 ≥ minPriceDistancePercent; Short (current−lastEntry)/lastEntry·100; and max margin: existingMargin + newMargin ≤ totalAssets·(maxMarginPerSymbolPercent/100) → 16. finalMargin = max(newMargin, 0) must be > 0 → 17. openPosition POST /api/create-position {symbol, direction, usdtAmount, leverage, tpPrice, slPrice, clientOrderId(new)} → 18. refresh balance, Bale notifyOpenPosition, persist.
   724→   724→- **Phase-17 direction-specific fields are stored but NOT used at trade time:** sizing uses legacy `entryMarginPercent`, `leverage`, `minPriceDistancePercent` (saveSettings sets legacy = the Long values). Only breakAtrMultiplier + rsi/volMult use Long/Short variants (in signal generation).

   800→   800→## D. Key audit findings / rebuild gotchas
   801→   801→1. **RSI off-by-one (HIGH):** rsi array length N−1 and shifted — callers read candle i+1's RSI for candle i; last analyzed candle uses the FORMING candle's RSI (repaint). ATR/SMA are aligned. Fix in rebuild: return length-N arrays (push placeholder at index 0).
   802→   802→2. **Dashboard HTF lookahead (HIGH):** market-signal-analyzer uses current-day lastClose (future info) vs prev-day levels. Automation options ('signalCandleClose' / 'previousDayClose') are both causal.
   803→   803→3. **shortFixedSl default = 6** → Short SL %-based by default while Long is ATR-based; fixed TP/SL are PERCENTAGES of entry.
   804→   804→4. **Direction-specific Phase-17 fields unused at trade time** — margin/leverage/price-distance use legacy (= Long) values only.
   805→   805→5. **Signal ID is local-timezone-dependent** (SYMBOL_YYYYMMDD_HHMMSS) and regenerated (Date.now()) for the actual exchange order.
   806→   806→6. Status vocabulary: 'در انتظار' / 'باز نشده' / 'منقضی شده' / open-time string (green) — no 'باز شده' literal; expiry only for the latest signal and only if never opened.
   807→   807→7. Candle-close = implicit (loop excludes last candle + full refetch every cycle); no openTime+interval check. minSameDirectionCandles includes the forming candle in its count.
   808→   808→8. Day boundary = **midnight Tehran (UTC+3:30)** via fixed +3.5 h offset; prev-day = previous day present in data; recovery/HTF levels are evaluated against the candle's own day context (not frozen at break time).
   809→   809→9. Same-candle break+recovery allowed (single-candle fake-out signal).
   810→   810→10. Break replacement only for OPPOSITE direction; same-direction re-break does not refresh the break candle (expiry counts from original break).
   811→   811→11. Legacy dead code in signal-utils: calculateTPSL + price-based calculateSignalStatus (unused).
   812→   812→12. Volume filter is `amount > 0.2 × SMA50(amount)` — low bar, not a spike filter.
